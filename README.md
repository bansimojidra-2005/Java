## ▶️ How to Run

### 1. Install Java

Make sure **JDK** is installed on your computer.

Check the Java version:

```bash
java -version
```

### 2. Clone the Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

### 3. Open the Project

Open the downloaded folder in your preferred IDE such as:

* VS Code
* IntelliJ IDEA
* Eclipse

### 4. Compile and Run

For a Java file:

```bash
javac ProgramName.java
java ProgramName
```
